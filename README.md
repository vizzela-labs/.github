# vizzela-labs/.github

Padrões de PR da organização **vizzela-labs**.

- [`CONTRIBUTING.md`](CONTRIBUTING.md): convenções de título, branch e o que é automatizado
- [`pull_request_template.md`](pull_request_template.md): template padrão de PR de todos os repos da org
- [`.github/workflows/`](.github/workflows/): workflows reutilizáveis (`reusable-pr-title.yml`, `reusable-pr-sync.yml`)
- [`workflow-templates/pr-padrao.yml`](workflow-templates/pr-padrao.yml): arquivo instalado em cada repo
- [`scripts/`](scripts/): lógica (JS) e `setup-repo.sh` para instalar num repo

Este repositório é **público** e não pode conter código de produto, dados nem segredos.
